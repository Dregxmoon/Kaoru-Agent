Kaoruは会話を集める中央サーバーを運営していません。記憶、埋め込み、設定、テレメトリーはローカルに保存されます。ただし、必ずしもオフラインではありません。選択されたメッセージや文脈はAIプロバイダーへ、音声合成用テキストはMicrosoftへ送信されます。有効にした連携、Webサイト、プラグインにも、作業に必要なデータが送られる場合があります。

3. 外部への送信と第三者

有効なLLMプロバイダーは、回答に必要なプロンプトを受け取ります。メッセージ、検索した記憶、システムの文脈、ファイルや接続先の内容、ツールの結果、視覚的な作業で使うJPEG/PNG画像が含まれる場合があります。組み込みのプロバイダーと互換エンドポイントに対応し、ローカルの接続先も選べます。利用可能な一覧はアプリ内に表示されます。

  • 選択したLLMプロバイダー：契約、地域、保持期間、データポリシーが適用されます。キーや接続先を追加する前に確認してください。
  • Microsoft Edge TTS：音声に変換するテキストを受け取ります。Voskの文字起こしは端末上で行います。
  • GoogleとGitHub：アカウントを接続して利用すると、端末から直接API呼び出しを送信します。
  • Webサイト：リクエスト、IPアドレス、入力したデータを受け取ります。各サイトのCookieとポリシーが適用されます。
  • プラグイン：実装に応じて文脈を受け取ったりコードを実行したりします。配布元と権限を確認してください。
  • カタログと更新：models.devの公開モデル情報やGitHubのリリースを照会する場合があります。この照会に会話内容を含める必要はありません。

Dregxmoonは個人データを販売せず、行動ターゲティング広告にも利用しません。設定した第三者への送信は端末から直接行われ、送信先の規約とポリシーも適用されます。

主な参照先：OpenAI、Google、Microsoft、GitHub。その他の接続先についても、そのポリシーを確認してください。

4. Google WorkspaceとLimited Use

Google Workspaceの組み込み連携は現在の公開版では利用できません。以前のインストールで連携が有効な場合、利用者がOAuthクライアントを用意し、Calendar、Gmail、Drive、Docs、Sheets、Tasks、Contactsなどのサービスとスコープを選びます。対応する機能では読み取り専用または書き込みを選べます。必要最小限の権限を許可し、不要になったら取り消してください。

Google APIから受け取った情報のKaoruによる利用と転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。利用者が依頼した目に見える機能の提供または改善に使い、販売、広告、無関係な目的での人への転送には使いません。メール要約など、依頼された操作に必要な場合に限り、選択したLLMプロバイダーへ送られることがあります。

5. デスクトップ、ブラウザー、権限

アプリ、ブラウザー、画面、ポインター、キーボード、プロセス、カメラには個別のスイッチがあります。allow・ask・denyのルールも適用されます。承認はリスクを減らしますが、結果を保証しません。

  • アクセシビリティ：LinuxではAT-SPI2、WindowsではUI Automationを使います。macOSの意味情報による操作は同等ではありません。
  • 画面とクリック：座標は撮影した画像にひも付き、30秒で失効し、一度だけ使えます。次の操作には再観測が必要です。画像は有効な画像対応LLMに送られる場合があります。
  • 個人のブラウザー：open_websiteはOSに既定のブラウザーでURLを開くよう依頼します。既存のセッションを使いますが、KaoruがCookieやパスワードを直接取り込むことはありません。
  • 管理対象ブラウザー：検索や検証を伴う処理は、独立した永続Chromiumプロファイルを使います。ログインした場合、Cookieは削除するまでKaoruのデータ領域に残ります。
  • プロセス：名前とIDを一覧表示し、終了を要求できます。対象を確認してください。終了後の状態が検証されない場合があります。
  • カメラ：現在の機能は状態確認とカメラアプリの起動のみです。写真撮影や録画はしません。

6. 保存とセキュリティ

記憶、セッション、テレメトリー、設定はElectronのローカルuserDataに保存し、埋め込みは端末上で計算します。認証情報はOSの安全な保存先（Keychain、Credential Manager、Secret Service）を優先します。利用できない場合、対応する代替経路により、自分のアカウントから読める設定ファイルや環境ファイルに認証情報が残ることがあります。端末、ファイル、バックアップを保護してください。ローカル保存はデータベース全体の暗号化を意味しません。

7. 保持と削除

データ 保持
アプリの履歴 30日後に自動削減します。
ローカルテレメトリー 最大90日です。
ログ 現在のファイルと一つのローテーション。それぞれ最大5 MiB。日数ではなくサイズで切り替えます。
ポインターにひも付く画像 メモリ上の参照は最大30秒または最初のクリックまで。外部に送ったコピーは送信先の規定に従います。
記憶とセッション 削除または減衰ルールによるアーカイブまで。アーカイブは論理削除であり、即時の物理削除ではありません。
管理ブラウザーのプロファイルとチェックポイント 手動または対応機能で削除するまで残ります。

Kaoruに記憶を忘れるよう依頼し、連携を解除するほか、設定 → 復旧とローカルデータ → Kaoruの全データを消去を使えます。明示的な確認後、Kaoruの設定、記憶、セッション、権限、キャッシュ、ローカル認証情報を削除します。プロジェクト、ドキュメント、ワークスペースは削除しません。Windowsの対話型アンインストーラーでも同じ削除を選択できます。OSのバックアップ、環境変数、外部プロバイダーには、それぞれ別の保持期間があります。

8. 権利と同意の撤回

アクセス、訂正、取消し、異議申立て（ARCOの権利）、利用の制限、同意の撤回を連絡先メールで依頼できます。内容を十分に説明してください。合理的な本人確認を求める場合があります。多くのデータは端末内にあり、ローカルでの閲覧や削除も可能です。

Googleの権限はGoogleアカウントの権限設定、GitHubは承認済みアプリの設定で取り消せます。取消しは将来のアクセスを止めますが、送信済みのコピーやバックアップを自動で削除するものではありません。

9. 権限のある利用と未成年者

利用権限のある端末、アカウント、ワークスペースのみで使用してください。他者に知らせず、同意なく監視しないでください。職場や教育機関の規則に従ってください。Kaoruは18歳以上、または適用される成年年齢以上の利用者を対象とし、未成年者のデータを意図的に収集するものではありません。

10. 変更

この公開Webサイトは、明るいテーマ・暗いテーマの選択をブラウザーのlocalStorageに保存します。 アクセス解析やフォームは組み込んでいません。画像、スタイル、スクリプトは同じサイトから配信します。 ホスティングはページ配信に必要なリクエストを処理します。外部リンクを開くと、移動先のデータの取り扱いも適用されます。

機能、プロバイダー、取り扱いに重要な変更があれば通知を更新します。日付が版を示します。合理的に可能な範囲で、重要な変更は適用前または適用時にリポジトリかアプリでお知らせします。
