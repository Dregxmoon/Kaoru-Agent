# Ventana de chat (`src/chat/`)

La ventana de conversación del asistente (renderer **aislado**: `contextIsolation: true`,
`nodeIntegration: false`, `sandbox: true` de Electron, `webSecurity: true`). La página
`src/chat.html` carga scripts locales (incluidos `marked` y `DOMPurify` desde `node_modules`) como
scripts clásicos en orden; solo ven el puente `window.assistant` construido por `preload.js`. Toda la
lógica Node corre en el proceso main en `ipc/chat-handlers.js` (registrado desde `main.js`); el
preload es un puente fino que solo expone `contextBridge` + `ipcRenderer` acotados.

> **Alcance:** este hardening es sobre el **sandbox del renderer de Electron** (`webPreferences.sandbox`),
> no sobre `contextIsolation` (sigue en `true`; son mecanismos distintos).

## Piezas

| Archivo            | Responsabilidad                                                                                                                                                                                                                                                                                                                                                  |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `preload.js`       | Preload **fino**: construye el puente `window.assistant` vía `contextBridge` con allowlists locales y cachés (`_llmCache`/`_cmdIndex`); `runCommand` (roundtrip a `ipc/chat-handlers.js`), `onUiCall`/`uiCallResult`, `refreshCapabilities`, `ttsStream`, `coreSources` y helpers async de fs/path. No carga módulos core: la lógica Node vive en `ipc/chat-handlers.js` |
| `core.js`          | Bootstrap (primer script): `renderMarkdown` completo con `marked` + `DOMPurify` (HTML crudo aislado en frame `sandbox`), loader async de core-sources (`initCoreSources`/`initCoreModules`), dispatch de comandos y modo agente/chat (`setAgentMode`/`getAgentMode`/`toggleAgentMode`/`onAgentMode`)                                                                 |
| `ipc.js`           | Listeners IPC: cierre, tema, mensajes entrantes, cambio de modelo/vistas, estado de OpenClaw, badge AGENTE con % de contexto, dispatcher `assistant.onUiCall` y gestos en propuestas                                                                                                                                                                              |
| `input.js`         | Entrada del chat: cursor de bloque estilo terminal, textarea multilínea, hints y autocompletado de comandos (`_getProjectFiles` async con `_atProjectFilesPromise`)                                                                                                                                                                                                |
| `messages.js`      | Render de mensajes: burbujas por rol, Markdown + mermaid, chips de archivos, streaming incremental, preview HTML y `loadLLMConfig` async (configura el `LLMProvider` vía main)                                                                                                                                                                                     |
| `activityBlock.js` | Bloques de actividad por tool (progreso del agente): líneas `Read()`/`Bash()`/`Edit()` con ok/err, expansión con diffs coloreados, spinner y reveal progresivo                                                                                                                                                                                                   |
| `process.js`       | Pipeline de proceso: compresión de historial si el asistente falla repetido, manejo del agent-run (pageData serializable + sync de `sessionHistory`), streaming y parseo de marcadores `(gesto: x)` para disparar animaciones en vivo                                                                                                                                                                                               |
| `sessions.js`      | Modal de sesiones pasadas: retomar conversaciones cerradas vía IPC `sessions-list`/`session-load`                                                                                                                                                                                                                                                                |
| `nodes.js`         | Vista del grafo de memoria (`/memoria`): layout force-directed (Fruchterman-Reingold) con nodos y aristas vía IPC `nodes-graph`                                                                                                                                                                                                                                  |
| `mcp.js`           | Panel de servidores MCP: listado, búsqueda en el registro, alta manual                                                                                                                                                                                                                                                                                           |
| `permissions.js`   | Panel de permisos allow/ask/deny (reglas persistentes vía `core/security/PermissionManager`)                                                                                                                                                                                                                                                                     |
| `tts.js`           | Síntesis de voz: mute, AudioContext y `cleanForTTS` (limpia Markdown/emoji/código/comandos antes de hablar)                                                                                                                                                                                                                                                      |
| `live2d.js`        | Mini-avatar Live2D (PIXI + live2d-display), cambio de modelo, vistas y errores (modelo aumentado vía main)                                                                                                                                                                                                                                                        |

Estilo en `src/chat.css` (incluye `agent-mode-badge`, `copy-toast` y `cancel-btn`); los estilos del
mini-avatar en `src/css/`. Al seleccionar texto en un mensaje aparece un toast de **copiar**, y el
flujo simple se puede **cancelar** desde el botón del header (`cancelSimple()`).
